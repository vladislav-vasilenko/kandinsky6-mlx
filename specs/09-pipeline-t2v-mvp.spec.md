## Goal

The first end-to-end MLX generation: cached text embeddings + seed → 10 PiFlow steps of the Lite-distill DiT → video VAE decode → audio decode → MP4 with sound, compared with the diffusers run from the same noise.

## Read first

- `pipeline_kandinsky6_ti2va.py` (0.42.1): `prepare_latents` (578), `prepare_audio_latents` (607), `__call__` (646–) — latent shapes from height/width/num_frames, audio latent length from duration, timestep scaling passed to the transformer, latent un-scaling before each decoder, output post-processing.
- Text-embedding cache format used by the study notebook (`generative-ai-research/kandinsky-6/generation/diffusers_runner.py`, `encode_prompts`) or a fresh one recorded by `reference/record_text_embeddings.py` written here.

## Deliverables

- `src/kandinsky6_mlx/pipelines/t2v.py`: `Kandinsky6Pipeline.from_converted(dir)`, `__call__(text_embeds, height, width, num_frames, seed | initial_latents, num_inference_steps=10, guidance_scale=1.0)` returning frames, waveform and timings.
- `src/kandinsky6_mlx/pipelines/export.py`: MP4 (H.264 + AAC) via PyAV.
- `scripts/generate.py` CLI.
- `reference/record_pipeline_run.py`: diffusers run saving initial noise, per-step latents, final frames and waveform (Kaggle or a machine with ≥ 32 GB RAM).
- `tests/e2e/test_pipeline_tiny.py`, `tests/e2e/test_pipeline_real.py` (marker `real_weights`).
- `reports/09-pipeline-t2v-mvp.json`.

## Implementation notes

- Initial video and audio latents are generated by NumPy or loaded from the reference record, never by `mx.random`, for the parity run.
- Free text-encoder memory is not an issue here: text embeddings come from a file.
- Run order and memory: DiT loop → free DiT → video decode → audio decode. Record peak memory per stage (`mx.get_peak_memory`).

## Tests

- Tiny e2e: tiny DiT + tiny VAEs + PiFlow, float32, matches a tiny diffusers pipeline run from the same noise (`rel_max <= 1e-3` on frames).
- Real (stage B): Smoke settings (256×432, 25 frames, 10 steps, seed 42, prompt from the study notebook):
  - per-step latent `cosine >= 0.999` and `rel_l2` within the AGENTS.md bf16 criterion relative to torch bf16 drift;
  - final frames PSNR ≥ 30 dB vs reference;
  - audio waveform SNR reported.

## Validation runs

```bash
uv run --group reference pytest tests/e2e/test_pipeline_tiny.py -q
uv run python scripts/generate.py --weights weights/lite-distill --text-embeds fixtures/real/smoke_text.safetensors --preset smoke --seed 42 --out outputs/09/smoke.mp4
uv run pytest tests/e2e/test_pipeline_real.py -m real_weights -q
```

Report: wall time per stage, peak memory per stage, chip, the metrics above, paths of the MLX and reference MP4.

## Acceptance criteria

- [ ] Tiny e2e passes.
- [ ] Stage B (if run): MP4 with audio produced; metrics meet criteria; a human check of the side-by-side video is recorded (`visual_check: same scene / differs`).

## Out of scope

Text encoders (spec 11), Baseline resolution (needs spec 10), I2V, CFG.

## Stop conditions

Per-step cosine drops below 0.99 at any step → `FAIL` with the step index and the per-block DiT drift at that step.
