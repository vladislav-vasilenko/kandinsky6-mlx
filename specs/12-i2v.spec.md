## Goal

Generate a video that starts from a given image, matching the diffusers I2V path.

## Read first

- `pipeline_kandinsky6_ti2va.py`: `encode_image` (551), `retrieve_latents` (165), the `image` branch of `__call__` (visual conditioning channels, `visual_token_type_ids`, `visual_rope_pos` with a repeated temporal index).
- `autoencoder_kl_hunyuan_video.py`: `HunyuanVideoDownsampleCausal3D` (121), `HunyuanVideoDownBlock3D` (284), `HunyuanVideoEncoder3D` (410), `_encode`/`encode` (764–804), latent distribution (mean vs sample — use what the pipeline uses).

## Deliverables

- `src/kandinsky6_mlx/models/video_vae/encoder.py`, I2V support in the pipeline (`image=`).
- `tests/parity/test_video_vae_encoder.py`, `tests/e2e/test_i2v_real.py`.
- `reports/12-i2v.json`.

## Implementation notes

- Image preprocessing (resize, crop, normalize to [-1, 1]) must match the reference pixel for pixel; test on a fixed PNG.
- If the pipeline samples from the latent distribution, pass a NumPy noise sample for parity.

## Tests

- Stage A: tiny encoder parity (`rel_max <= 1e-4`); preprocessing equality on a fixed image.
- Stage B: real encoder on a fixed image (`rel_l2 <= 1e-3`); I2V Smoke run from recorded noise, first-frame PSNR and per-step cosine as in spec 09.
